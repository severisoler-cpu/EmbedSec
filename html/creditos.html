Créditos

Este proyecto ha sido desarrollado como trabajo práctico del módulo de Servicios en Red del ciclo formativo de Sistemas Microinformáticos y Redes (SMX).

Sobre el proyecto

Autor

Proyecto realizado por Marc Severí, de 2º de SMX, como trabajo de investigación sobre seguridad inalámbrica y herramientas de auditoría con hardware embebido.

Tecnologías usadas

  • HTML5 y CSS3 — Estructura y diseño del sitio
  • JavaScript — Animaciones y simulador de firmware
  • LilyGO T-Embed CC1101 — Hardware de auditoría
  • Firmware Bruce — Software del dispositivo

Código fuente

Escrito a mano en HTML, CSS y JavaScript sin usar frameworks ni plantillas de terceros. Los iconos SVG son de Feather Icons (feathericons.com).

Fuentes consultadas

Documentación oficial de Espressif (ESP32-S3), repositorio de Bruce en GitHub, y material del módulo de redes del ciclo SMX.
